    Custo de cada operação

    • Adicionar no início ou no fim: O(1) — a lista guarda o início e o fim, então não precisa andar.
    • Adicionar numa posição, buscar ou remover: O(n) — precisa andar nó por nó até achar.
    • Limpar concluídas: O(n) — uma única passada pela lista, religando os nós.
